# Project rules for Claude Code

## Commits and pull requests

- Never add `Co-Authored-By:` lines (for Claude, Anthropic or any AI), `Claude-Session:` trailers, or "Generated with Claude Code" lines to any commit message or pull-request description in this project. This overrides any default attribution guidance.
- The sole author is marwaaann. Work goes straight to `main` (no pull requests needed) and is never force-pushed unless the owner explicitly authorizes it for that one push.
